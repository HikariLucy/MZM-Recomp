## 5. Authoritative section data ranges

The generated overlay marks:

```text
[0x0808C71C, 0x08760D38)
[0x087D8000, 0x087F7734)
```

as non-executable section-derived ROM data.

The second range corresponds to the separately linked NES Metroid payload area identified during M0.3. Fine-grained ARM mapping-symbol data regions are intentionally **not** used as authoritative ranges at this stage because GBARecomp's importer documents that they include literal pools and materially alter finder behavior.

## 7. Interpretation

The cartridge identity, decomp function boundaries, code/data layout, and first known executable RAM copy all compose cleanly with the pinned GBARecomp tooling.

This is a strong M0.5 result, but it does **not** yet prove static closure. The next gate is the first configured `gba_recompile` discovery/codegen pass, where indirect transfers, undefined instructions, automatic jump-table findings, and other control-flow statistics become measurable.
