### Interpreting the 28,346 count

This number must **not** be compared directly with the decomp's 2,722 source-level functions.

GBARecomp's finder treats discovered control-flow roots as translation units. Direct branch targets, switch/case targets and other independently reachable PCs can become separate generated entries even when they lie inside what the decomp/source model considers one function.

Therefore:

- **2,722** = imported semantic/decomp function entries;
- **28,346** = finder/emitter translation roots for native dispatch/codegen.

The large count is not, by itself, evidence of bogus functions.

### Imported seed value

Of the 2,722 imported decomp seeds:

```text
2099 were also discovered by the finder
624 were seed-only and would otherwise be lost
```

This confirms that the byte-matching decomp overlay materially improves static reachability, especially for address-taken/indirectly referenced code.

### Undefined instruction result

```text
undefined=0
```

No decoder-undefined ARM7TDMI instruction was encountered in the discovered corpus. This is a strong feasibility result: the normal cartridge code reached by this analysis does not presently expose an unsupported CPU-instruction category.

This does **not** prove runtime correctness or full static closure.

## 11. M0.5 conclusion

M0.5 is **CONFIRMED** as a static-analysis feasibility gate.

The first configured GBARecomp pass:

- validates the exact cartridge identity;
- accepts the decomp-derived executable/data split without contradiction;
- preserves meaningful decomp names;
- models the known startup IRQ code copy;
- discovers and emits indirect/switch-heavy control flow;
- encounters zero undefined CPU instructions;
- successfully writes the complete generated C++ corpus.

No fundamental static-analysis blocker was found for the normal Zero Mission code corpus.

This is **not yet** a claim that the generated source compiles into a runnable MZM executable, that boot succeeds, or that strict-static runtime closure is achieved. Those are later milestones.
