# Xbox Series X|S / UWP Build & Toolchain Guide

## Prerequisites & Microsoft Toolchain

To compile MZM Recompiled for Xbox Series X|S / UWP (`x64`), the build host must be Windows 10/11 with the following components installed:

1. **Visual Studio 2022** (Community, Professional, or Enterprise)
   - Workload: **Universal Windows Platform development** (`Microsoft.VisualStudio.Workload.Universal`)
   - Individual Components:
     - MSVC v143 - VS 2022 C++ x64/x86 build tools
     - C++ Universal Windows Platform support for v143 build tools
     - C++/WinRT compiler and libraries
     - Windows 10 SDK (version 10.0.19041.0 or higher) or Windows 11 SDK (10.0.22621.0)
2. **CMake 3.25+** (included with VS 2022 or installed standalone)
3. **Git** with submodule support

---

## 1. Building SDL2 for UWP (WinRT x64)

SDL2 provides an official WinRT project located in `VisualC-WinRT/SDL-UWP.vcxproj`:

```cmd
:: Open VS 2022 Developer Command Prompt for x64
msbuild VisualC-WinRT\SDL-UWP.vcxproj /p:Configuration=Release /p:Platform=x64 /p:AppxPackage=false
```

This outputs `SDL2.dll` and `SDL2.lib` compiled for UWP x64.

Alternatively, using CMake:
```cmd
cmake -S . -B build-uwp -G "Visual Studio 17 2022" -A x64 ^
  -DCMAKE_SYSTEM_NAME=WindowsStore ^
  -DCMAKE_SYSTEM_VERSION=10.0 ^
  -DSDL_STATIC=OFF ^
  -DSDL_SHARED=ON
cmake --build build-uwp --config Release
```

## 2. Configuring & Building MZM Recompiled for UWP

### Step A: Submodule Initialization
Ensure all dependencies are checked out at their pinned commits:
```cmd
git submodule update --init --recursive
```

### Step B: CMake Configure (WindowsStore / UWP target)
```cmd
cmake -S . -B build-uwp -G "Visual Studio 17 2022" -A x64 ^
  -DCMAKE_SYSTEM_NAME=WindowsStore ^
  -DCMAKE_SYSTEM_VERSION=10.0 ^
  -DGBARECOMP_ROOT=path\to\gbarecomp ^
  -DRECOMP_UI_ROOT=path\to\recomp-ui ^
  -DMZM_PLATFORM_UWP=ON ^
  -DSDL2_DIR=path\to\sdl2_uwp_cmake ^
  -DCMAKE_BUILD_TYPE=Release
```

### Step C: MSBuild Compilation
```cmd
cmake --build build-uwp --config Release --target MZMRecomp
```

## 4. Packaging with MakeAppx & Signing

### Step A: Pack MSIX / AppX
```cmd
MakeAppx.exe pack /d dist\uwp-staging /p dist\MZMRecompiled-Xbox-x64.msix /nv
```

### Step B: Development Self-Signed Certificate
Generate test certificate (PowerShell):
```powershell
New-SelfSignedCertificate -Type Custom `
  -Subject "CN=MZMRecompiledDev" `
  -KeyUsage DigitalSignature `
  -FriendlyName "MZM Recompiled Dev" `
  -CertStoreLocation "Cert:\CurrentUser\My" `
  -TextExtension @("2.5.29.37={text}1.3.6.1.5.5.7.3.3", "2.5.29.19={text}")
```
Export public certificate (`MZMDev.cer`) and PFX (`MZMDev.pfx`).
> **CRITICAL**: Never commit `.pfx` or private keys to the git repository.

### Step C: Sign the Package
```cmd
SignTool.exe sign /fd SHA256 /a /f MZMDev.pfx /p YourDevPassword dist\MZMRecompiled-Xbox-x64.msix
```

The resulting `MZMRecompiled-Xbox-x64.msix` is ready for deployment via Xbox Device Portal.
